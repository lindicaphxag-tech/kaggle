# SemRepair Prospective Evidence Transport

This repository is a **public timestamp/evidence transport surface** for the
SemRepair embodied-software research line. It is not the flagship method
repository and it does not award itself research credit.

Its only intended role is to:

1. scan a frozen, metadata-selected set of public embodied/robotics repositories;
2. persist the original first-seen issue surface before comments, linked fixes,
   or maintainer diagnosis are inspected;
3. bind that surface to a canonical SHA-256 and prediction deadline;
4. allow post-hoc resolution evidence to be opened only after an immutable
   prediction digest has been committed.

A captured issue is **not** automatically an I2 case, a mechanism match, an
external adoption, or evidence that SemRepair is correct. Eligibility and
adjudication remain separate.

The transport starts from a new public activation boundary; it does not
retroactively upgrade earlier private observations.
