# SemRepair — high-tier robot-systems research gate (2026-10-10)

**Status:** protocol and reviewer-attack document; not a publication, unseen-source test, or external adoption.

## Primary novelty and closest threat
SemRepair's potential new scientific object is **evidence-limited authority to perform one concrete, implementation/evidence/dependency-bound repair when semantic action interfaces are undeclared, untrusted or compensating**.

Not new: known-convention gauge transport, semantic action normalization, active system identification, optimal adaptive decision trees, interval intersections, or first-order local robot repairs. GaugeBench (arXiv:2610.07597) and ExecSpec (arXiv:2606.03724) are mandatory closest prior art.

## Decisive blinded experiment
**Unit:** independent hidden *interface-world family*, not every correlated robot rollout. A world combines producer convention, controller convention, action saturation, parameter nuisance, and a concrete implementation patch hash. The *author-side scorer* may access hidden source/truth; the *diagnosing algorithm* must not.

1. External judge samples transforms, actuator nuisance and compensating pairs from a **predeclared** generator and seals hidden parameters/patch identity.
2. Method receives only admissible public trajectories and an action/tap menu: each tap has cost, physical risk, and availability. It cannot inspect the generator, source diffs, SHA-to-authority lookup, or scorer.
3. Algorithms allocate probes and/or internal taps until all surviving worlds authorize the **same** patch+implementation+evidence+dependency tuple, or refuse on ambiguity.
4. Replay authorized repair in a different target episode / native controller; preserve both failed and successful execution as original raw records.
5. Freeze world families, source snapshots and source-selection criteria *before* any outcome inspection. Historical PegInsertionSide episodes 0–99 are development-exposed; must not be called globally untouched.

### Fair baselines
- deterministic guess / metadata-only;
- exhaustive identify-all-parameters policy;
- entropy/info-gain diagnosis with the **same probes/taps/risk budget**;
- decision-region / equivalence-class determination baseline on the same frozen hypothesis set;
- always-refuse and always-ask-private-tap;
- known-convention exact transport as an *upper bound*, not a fair unknown-convention competitor.

### Four separate outcomes (never collapse)
1. official demonstration conversion success (data loading/replay);
2. **wrong repair authority** / unwarranted acceptance, with refusal count;
3. physical end-effect error and independent repair closure;
4. learned-policy downstream task success under frozen policy, if actually evaluated.

Include per-family signed effect and failure-only repair regression, probe/tap cost, false refusal and wrong-authorization cost; resample at independent **world family/source initial-state cluster**, never count dependent A/B or 2×2 cells as independent robots.

### Stop criteria
- No unseen hidden-source test without leakage -> only finite illustrative theorem/mechanism report.
- Same probe/tap and risk budget baseline closes advantage -> stop "optimal" advantage claim.
- Only converter compatibility but no repaired executed policy benefit -> paper must remain a *software interface-correctness* contribution, not a learned-policy success claim.
- If required distinguishing internal evidence is unaffordable, label **unidentifiable**; never turn conservative refusal into positive rescue.
- Author-run CI or own-repo merge is not an outside maintainer's acceptance.
