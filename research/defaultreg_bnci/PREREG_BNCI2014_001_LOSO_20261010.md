# Default Regularisation — BNCI2014_001 full LOSO preregistration

Frozen 2026-10-10 before any target-subject score from this branch is opened.

## Dataset

- BNCI2014_001 / BCI Competition IV 2a.
- 9 subjects, 22 EEG channels, 2 sessions.
- Only left-hand vs right-hand trials; all available original trials returned by
  MOABB with dataset artifact handling fixed to IGNORE and paradigm
  reject_by_annotation=False. The exact MOABB version and resulting per-subject
  trial count are archived.
- Wide 8–30 Hz representation only in this first external run.
- Epoch interval: 0.0–4.0 s of the standard MOABB left/right imagery epoch.
- No participant may be removed after target results are observed.

## Outer evaluation

Nine leave-one-subject-out folds. In each fold:
- one participant is target only;
- the other eight participants are source only;
- tangent reference, regularisation selection and all model fitting use source
  participants only;
- target trials are transformed with the frozen source reference individually;
- target labels are used only after all score vectors are produced.

Participant is the inferential unit.

## Fixed methods and roles

Classical baselines:
1. LedoitWolf LDA
2. OAS LDA
3. source-group LOPO macro-AUC tuned scalar shrinkage LDA
4. LogisticRegression C=1

Mechanism controls:
5. source squared standardized-margin scalar shrinkage (polarity-blind)
6. source signed-mean standardized-margin scalar shrinkage

**Primary new criterion:**
7. source lower-tail signed standardized-margin scalar shrinkage, with frozen
   tail_fraction=0.25 and lambda grid {0.2,0.4,0.6,0.8,0.95}.

This primary choice is fixed before viewing any outer target AUC. It may fail.

## Primary questions

P1. Does the primary tail-signed selector produce a positive paired subject
AUC delta relative to the strongest *predeclared scalar source-only baseline*,
source-LOPO macro-AUC tuned shrinkage?

P2. Does it reduce hard-subject harm? Report median, lower quartile, minimum
paired delta and count of target participants harmed by >0.02 AUC.

P3. Do analytic LedoitWolf/OAS strengths differ from source-discriminability
selected scalar strengths, establishing the proposed regularisation-target
mismatch mechanism even if the new algorithm does not win?

P4. Does the squared-margin control select differently in folds with negative
source-participant transfer margins, supporting the polarity-blindness
mechanism? This is descriptive mechanism evidence, not proof about future
targets.

## Statistical and interpretation gate

- Report all 9 paired target results and exact failures.
- With N=9, exact sign-flip is possible but low power; treat this dataset as an
  external replication stratum, not the entire journal evidence.
- No algorithm may be retuned on target outcomes. Any post-outcome method
  modification requires Cho2017 / Lee2019 as untouched future cohorts.
- Do not claim superiority over published deep methods from cross-paper
  accuracy comparisons.
- A positive result against LedoitWolf but not against correctly nested
  source-LOPO shrinkage supports the mismatch phenomenon, **not** algorithmic
  superiority.
- BSPC-level claim still requires additional frozen external cohort(s).
