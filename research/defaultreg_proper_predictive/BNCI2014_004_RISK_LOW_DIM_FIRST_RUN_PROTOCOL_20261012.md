# NEW independent low-dimensional EEG + subject-tail risk sensitivity experiment
Frozen before first execution on `BNCI2014_004`, 2026-10-12.

Dataset: MOABB 1.7.2 `BNCI2014_004`, BCI Competition IV 2b; 9 subjects, 3 bipolar EEG + 3 EOG (exclude EOG), up to five sessions per subject, two classes left-hand and right-hand motor imagery. Freeze `MotorImagery(n_classes=2,events=['left_hand','right_hand'],fmin=8,fmax=30,resample=160,baseline=None,reject_by_annotation=False)`, original 2026-10-10 `original_frozen_runner.py` covariance/tangent-space/LDA stack and all available sessions. Stop if channel count !=3, subject IDs incomplete or classes missing. Do NOT assume MOABB's number of retained trials ahead of filtering; report actual 9 separate denominators and dropped/unknown exclusions. Original source groups' 5 folds fixed by ascending source subject IDs.

**Scientific objective**: Does the historic-vs-proper covariance validation estimand effect survive a fundamentally changed 3-channel (tangent p=6) recording geometry? Does a SOURCE-only downside-risk choice (lower 25% of held-SOURCE-person AUCs across the same grouped validation folds) reduce the number of held target people seriously harmed, compared with mean source AUC, source-mean predictive Gaussian NLL, historical validation class-centred covariance Gaussian score, Ledoit--Wolf and OAS? The source-CVaR selector is a known distributionally robust criterion, not claimed novel by itself. Its target AUC may underperform, be equal, or outperform; any outcome must be reported.

**Frozen per outer-person procedure**: Hold exactly one of 9 people. Using other 8 SOURCE people only, fit the original 5-fold group-SOURCE tangent geometry separately in each inner split. For each candidate in the original `FULL_GRID` feasible across ALL inner SOURCE groups: measure held-source-person ROC-AUC. `lambda_CVaR` maximises the average of the **worst 2/8 source-person AUCs**, break ties to smaller lambda. Fit no held-target features or labels during CV. Select other three lambdas using original `source_path` source macro-AUC, its class-centred covariance score, and genuine Gaussian class-conditional proper predictive NLL using exclusively SOURCE-TRAIN group means. All select from *the identical original source-feasible full grid*.

Output 9-choice JSON with SHA256 **before any outer target AUC is evaluated**. Once choices are locked, fit source-only final tangent geometry/classifier, measure all six target AUCs. Also report subject-level harms (>0.02 AUC), source mean-shift penalty at proper lambda, and whether the source-CVaR choice improves/downshifts target tail performance. Do NOT choose a risk fraction, grid, preprocessing, batch or analysis after viewing outcomes.

**Novelty and inference**: The rigorous new mechanism is exact estimand definition and decision-breakpoint sensitivity, while source-CVaR is an external, well-known comparator that tests tail-risk relevance. The dataset is independent in recording apparatus, with much lower feature rank. The GitHub freeze is not a third-party preregistration or proof the authors have never encountered this dataset.
