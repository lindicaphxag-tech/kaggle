\subsection{Six further DreyerB held people under earlier frozen choices}
\label{sec:p3-dreyerb-six-new}
We next attempted a strict byte-identity extension of
the previously source-locked Dreyer2023B study.
The original GitHub Actions source-lock file from
run 38390737635 was downloaded and checked
\emph{before} opening any newly held target.
Although the subject IDs, trial counts, class
counts and core installed numerical library
versions agreed, recomputing the source
covariance-feature bytes produced a different
SHA-256 (original:
\texttt{7146797e...3e172b2a7};
recomputed:
\texttt{9f650460...39ada7f65}).
Consequently the strictly \emph{byte-identical}
source-replay experiment failed closed
\emph{before} opening any of the six newly
held participants. We preserve both failed
receipts. The cause of the fingerprint mismatch
is unresolved and the original fitted
classifier cannot be claimed to have
been reproduced.

A separately labelled \emph{lower-tier} protocol
then used the \emph{prior immutable choice of all
five source-only policy hyperparameters},
without reselecting parameters from the
previously observed target people 69--70
or any newly held target. It refitted the
source covariance/tangent model using the
reloaded 61--68 source participants, confirmed
the source participant/trial/class accounting
against the original receipt, and recorded the
old versus new source hashes prior to opening
held IDs 71--76. Each newly read subject
contributed 240 labelled left/right motor
imagery trials. All comparison policies
shared the same refitted source pool and
one held target at a time. The source
feature SHA drift, original unchanged
choices and six held outcomes are recorded
in successful
\href{https://github.com/lindicaphxag-tech/kaggle/actions/runs/38537617142}
{run 38537617142}.

Across these six within-cohort held people,
none of the complex choices had a positive
descriptive mean advantage over source macro.
Anisotropic selection lost more than 0.02
AUC on held ID 76. In contrast, the
earlier new BNCI2015\_004 mental-task
participant had a small positive SCE
effect. This mixture illustrates
task/cohort sensitivity; it neither
demonstrates a population-equivalence
null nor proves any risk-calibrated
source-only abstention policy.
Six held \emph{people} are still only
one acquisition cohort, and the two
source-model versions in this study
are explicitly not combined into a
confirmatory acquisition-level
effect or conventional $p$ value.
