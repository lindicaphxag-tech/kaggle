## Evidence hierarchy / exact release tests
G0 Provenance: V30 49-group findings independently attested, but physically
independent patient identities are not established. Do not claim patient-level
leakage bias. PASS only for processed-record identity.
G1 Math: V31 exact ellipsoid witness, LDA path equivalence, scale invariance,
unrestricted-shift reversal, invalid input rejection; GitHub CI test result
is a code-correctness receipt, NOT target evidence.
G2 Source-only first-run: fixed Cho2017 12 source IDs/20 held IDs;
source choice manifest and digest must precede any held EEG read.
Primary new lambda may equal original macro lambda; in this case the entire
claimed selection gain is EXACT ZERO and the negative result is retained.
The V31 first run has not been added to manuscript conclusions before
the real CI returns frozen target outcomes.
G3 Primary statistical gate: subject-macro paired effect SCE-rho1 minus
source-grid, subject-level 20 rows, exact two-sided sign-flip p<.05,
nonincreasing number of >.02 harmed target subjects. Multiplicity for
other methods is explicitly exploratory, not retroactive confirmations.
G4 Independent replications: additional acquisition(s) with genuinely
different recording conditions and prospective protocol locks; no fitting
radius or selecting feature dimensions against the Cho held outcomes.
G5 Broader matched-budget controls: source macro, properly predictive NLL,
Ledoit-Wolf/OAS are essential but not enough to claim superior BCI decoding.
Add Riemannian MDM, tangent-space logistic regression, CSP/logistic regression,
and a domain-generalization comparator when information budgets match.
G6 Statistical validity: record group, not trial, is inferential unit; one
cohort of 20 is not cross-study evidence. Report signed per-person harms and
LOPO/source-pool dependence; use sensitivity and repeated independent cohorts.
G7 Editorial: paper A should not absorb V26-V31 as independent headline
inventions. Results tables, vector figures, baselines, limitations,
author / ethics / funding / AI disclosure, references, data/code link and
journal-specific presentation must all match the final source and executable CI.

## Current novelty threshold relative to prior art
- Regularised LDA / covariance shrinkage: classical.
- Source-only domain generalization: extensive established EEG literature.
- Ellipsoidal Cauchy-Schwarz bounds: classical robust optimization.
- Group identity and leakage-safe split validation: important existing work.
Therefore a proposed flagship contribution requires **a novel empirical
transfer mechanism that predicts decisions before unseen outcomes and
improves them under falsifiable source-only constraints**, not simply
more complexity or another algorithm acronym.
