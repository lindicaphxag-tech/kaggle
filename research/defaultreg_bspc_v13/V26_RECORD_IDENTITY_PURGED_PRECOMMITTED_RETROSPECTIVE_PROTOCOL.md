# V26 original-signal group-purged EEG sensitivity study (2026-10-13)

**Status: retrospective, initiated AFTER Liu2024 50-person outcomes and the V25 signal-identity warning were exposed.** This is NOT pre-registered or independent confirmation, and is not a strict target-unseen Z0 experiment because determining global recording identities inspects EEG signals before model selection.

## Why this study is essential
The previous 50-person source-locked analysis assumed patient IDs index independent EEG recordings. Its independent audit found pairs of identical method-wise held-person AUC vectors (4/5 and 47/49), and the two-person forensic inspection established **identical MOABB-preprocessed signal arrays for 4/5** though released EDF numeric content and byte hashes differ. The 47/49 source arrays were not identical. The ongoing all-50 scan is the decisive record-identity ledger; do not infer true patient ID duplication or clinical cause from score-vector coincidences.

When two distinct subject IDs provide the same feature-bearing recording, the original leave-one-person-out split may train a model on a copy of the nominally held-person recording. This invalidates the intended record-independent transfer estimand. It is NOT enough to de-duplicate only the final participant-mean AUC while leaving training contamination intact.

## Frozen retrospective algorithm
- Read public Liu2024 subjects 1..50, original MOABB==1.7.2 preprocessing (binary left/right motor imagery, 8–30Hz, 160Hz, 29 EEG channels, 40 epochs per ID). No changed feature representation, leakage budget, class balance, preprocessing or patient exclusion based on target score.
- Compute SHA256 of the exact float64 preprocessed signal matrix and of binary event labels for each subject ID. Merge only subject IDs with **exactly identical full signal arrays and exactly identical label vectors**. If a repeated signal hash disagrees in labels, fail closed. Pairwise AUC-vector coincidence alone is not grounds for merging. No approximate threshold/cherry-picking.
- Use the smallest original subject ID as the deterministic representative of each exact recording-identity group; exclude all other copies from both training and the group-level target denominator. Every representative's source training set consists of ALL OTHER representatives only, with no identical preprocessed recording anywhere in source. Note that study has now been conditioned on a global signal audit; this is not strict unobserved-target-selection.
- Fit the unchanged source-trained Riemannian tangent representation, original 27-point grid LDA, original class-centred covariance criterion, source-macro AUC criterion, properly source-mean predictive Gaussian criterion, Ledoit–Wolf and OAS. Correct predictive NLL and source-macro may differ. Do not introduce extra V23/V25 selection heuristics with previously observed negative results.
- First freeze ALL group-safe source decisions, group membership, preprocessing receipts and SHA256 to disk. Only after this frozen manifest is written may evaluate target labels/scores for the representatives; this chronological separation is an audit against post-outcome tuning, NOT proof of independent untouched evaluation.
- Report number of **independent processed recordings**, number of excluded exact copies, actual numbers of EEG trials used, participant macro AUC, per-record harm >0.02, descriptive paired intervals and operation costs; compare descriptively with the exposed original 50-ID AUC. Never claim a new significant improvement or causal attribution of leakage from this observational sensitivity.
- If all 50 recordings are unique, the full audit is a negative result: preserve and do not invent duplicates. If output matches previous number by coincidence, report actual.
- Fail closed on nonfinite signal, missing subject, unexpected sensor/trial labels, source-target recording collision, class mismatch within exact-signal groups, missing original decision candidates, or source model mismatch.
- The all-50 signal identity ledger and first-run clinical source choice manifest remain separate immutable evidence; share cryptographic hashes only, never raw patient signals.
