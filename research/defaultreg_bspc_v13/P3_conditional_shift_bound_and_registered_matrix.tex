\section{A testable conditional transfer bound and new study design}
\label{sec:p3-conditional-transfer}
The earlier source-only indistinguishability counterexample
does not mean all guarantees are logically impossible.
It means a guarantee requires a \emph{testable and
nontrivial restriction} on the unseen target law.

For a \emph{fixed} scoring rule $w$, define the positive
and negative class-conditional source and target
distributions $P^+_S,P^-_S,P^+_T,P^-_T$, and assume
\[
 d_{\mathrm{TV}}(P^+_S,P^+_T)\le\epsilon_+,
 \qquad d_{\mathrm{TV}}(P^-_S,P^-_T)\le\epsilon_- .
\]
Because ROC-AUC is the bounded expectation of the
pairwise rank kernel
$\mathbf{1}\{w^\top x^+>w^\top x^-\}
+\tfrac12\mathbf{1}\{=\}$,
a product coupling gives the elementary bound
\[
 |\mathrm{AUC}_T(w)-\mathrm{AUC}_S(w)|
 \le \epsilon_++\epsilon_-.
\]
For two fixed policies $a,b$, this entails
\[
 \mathrm{AUC}_T(a)-\mathrm{AUC}_T(b)
 \ge \mathrm{AUC}_S(a)-\mathrm{AUC}_S(b)
      -2(\epsilon_++\epsilon_-).
\]
The inequality is intentionally conservative and
its TV assumptions are \emph{not established} for
the existing EEG data. In the actual Z0 setting,
unseen target distributions cannot be estimated
using target EEG or labels; therefore these
unknown radii cannot be silently set to zero
or treated as source-only learned confidence bounds.
The identity suggests an explicit research question:
\emph{which externally validated structural shift
restrictions allow a source-only score margin to
forecast target-person benefit?} It does not
by itself supply a deployable EEG predictor.

\paragraph{Necessary common-matrix experiment.}
Before any new target data are opened, freeze the
source feature byte digest, software revision,
recording-group component splits, target-information
budget, common preprocessing/montages, candidate
procedures and pairwise primary estimand. Every
candidate must be compared on the same held
recording groups, with a shared baseline, rather
than different methods on different datasets.
A primary endpoint is pre-target selected
model regret
$R_g=\max_{m\in\mathcal M}\mathrm{AUC}_g(m)
-\mathrm{AUC}_g(\widehat m_S)$;
a distinct harm endpoint is the fraction of
held groups where
$\mathrm{AUC}_g(\widehat m_S)
<\mathrm{AUC}_g(m_0)-0.02$.
Use hierarchical acquisition-level summaries
and disclose correlations from overlapping
source-training groups; do not turn all
outer folds into independent acquisitions.

A synthetic machine-readable source-manifest
regression enforces a fail-closed
SHA-256 source feature commitment and blocks
any non-Z0 target budget before target access.
This test is infrastructure only: \emph{no}
two previously unknown EEG acquisitions, new
held-person AUCs or empirical TV estimates
have been generated by it. A valid journal
submission remains conditional on those experiments.
