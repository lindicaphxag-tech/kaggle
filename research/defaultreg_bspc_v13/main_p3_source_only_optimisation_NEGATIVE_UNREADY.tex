\begin{abstract}
\textbf{Objective.} Can increasingly precise or structured source-only
regularisation optimization improve unknown-participant EEG decoding
without access to target signals or labels?
\textbf{Approach.} We retain a case series of separately executed
source-locked protocols, using the original participant-grouped
27-point shrinkage LDA as a reference, and distinguish a
continuous source optimizer, a source-contrast envelope (SCE),
an anisotropic covariance proposal and a classical
group-centred discriminant operator. Individual and
group-mean ROC-AUC changes, exact source-freezing evidence
and mathematical degeneration are recorded without pooling
dissimilar algorithms as if they were a single policy.
\textbf{Results.} On Weibo2014 (10 people) the continuous
choice was identical to the original grid (both 0.731405 macro
ROC-AUC). Cho2017 (40 target people) gave a pooled SCE-minus-grid
difference of $-0.00005264$, with SCE selecting the fixed-full-shrinkage
endpoint, invalidating a nondegenerate novel-operator claim.
The Dreyer2023A anisotropic design selected zero anisotropy
and differed from the baseline by $-0.001088$ ROC-AUC on 12 people.
A separate pre-target Lee2019 group-centred estimator selected
$\lambda=0.15$ versus original $0.4$ and had source-forecast
NEGATIVE; its first untouched 12-person block yielded
$-0.003933$ AUC (exact two-sided paired sign-flip $p=0.1289$).
A planned second Lee block did not produce interpretable
outcomes, because a bitwise source-covariance SHA check rejected
the separately run setup BEFORE accessing target data.
\textbf{Conclusions.} Two new retrospective
\emph{identical six-policy matrices} on
BNCI2014\_004 ($n=9$) and Weibo2014 ($n=10$)
yielded source-macro versus proper predictive-NLL
macro AUC of 0.778002 versus 0.776581, and
0.731405 versus 0.729358, respectively.
Source-macro's post-target six-policy oracle
regret averaged 0.000840 and 0.001766 AUC.
These were previously exposed public acquisitions.
A further same-source BNCI2014\_004 comparison included
the four original proposal families on one exposed held
person: continuous $0.836798$, SCE $0.836111$,
anisotropic $0.837199$, group-centred $0.833935$
versus source macro $0.836798$ ROC-AUC.
No universal negative theorem or new
superior decoder is established.
\end{abstract}
\noindent\textbf{Keywords:} EEG; motor imagery; transfer;
source-only model selection; negative results;
domain-shift generalisation; reproducing frozen protocols.

\section{Introduction}
Covariance-shrinkage and Riemannian tangent decoding have
long been established for EEG signals
\cite{barachant2012,jayaram2018moabb}.
Higher-precision optimisation over a source-only criterion
is not guaranteed to deliver transfer improvements when the
target distribution is unknown. Evidence on incorrect
EEG evaluation units \cite{gil2026subjectvalidation} and
multi-paradigm subject normalization
\cite{qin2026spatialnorm} motivates explicit distinctions
between source-policy optimization and target outcome.
Unlike the related estimand-mismatch study (P1),
the outcome here is the realised, pre-target-frozen
selection/action of each concrete candidate algorithm.
The four tested operators, however, were not
precommitted as one hypothesis family, and their source
cohorts and targets differ; this limits general conclusions.

\section{Materials and methods}
\subsection{Zero-target source selection and fixed score family}
All target-agnostic models train on known source EEG.
Original comparison for each study is the same
27-point source-macro AUC-selected scalar pooled-LDA
path with source-only tangent geometry.
The original scalar shrinkage family is
$A_{\lambda}=(1-\lambda)S+\lambda\operatorname{tr}(S)I/p$;
candidate procedures modify the choice of $\lambda$,
source uncertainty objective, or covariance/contrast
definition. No target EEG feature moments or target labels
enter the reported SOURCE selection. Nonidentical
candidate methods are not treated as one shared
algorithm and no formal cross-cohort combined $p$-value
is calculated.

\subsection{Precision and source-contrast families}
The Weibo2014 acquisition tested a finite 27-point
source-macro selector against continuous source criterion
optimization, using the same C3/Cz/C4 EEG feature
pipeline. Cho2017 tested a pre-data source-contrast
envelope against the same original source-macro grid,
followed by a reserved group without parameter updates.
The second Cho block was protocolized AFTER seeing
the first-block results, so its inferential status is
sequential-exploratory. The Dreyer noise-debiased
covariance-contrast method selected its anisotropy
parameter on source people; $\alpha=0$ corresponds
to the original scalar family.

\subsection{Source-group nuisance invariance}
Let $\mu_{gc}$ be each source person's class mean.
A further classical within-group operator uses
\[
 W={\sum_{g,c}\sum_{i\in(g,c)}
 (x_i-\mu_{gc})(x_i-\mu_{gc})^\top\over N-2G},
 \quad
 d_{\rm eq}={1\over G}\sum_g(\mu_{g1}-\mu_{g0}).
\]
For an arbitrary common translation applied to
each source participant in FIXED feature coordinates,
both $W$ and $d_{\rm eq}$ stay unchanged. This is
standard within-group discriminant analysis,
not a new generalization theorem, nor invariance
to refitting a nonlinear EEG reference.

On Lee2019\_MI, source IDs 1--12,
target A=13--24, and reserved B=25--36
were defined before data access. Using grouped
source macro-AUC, a positive transfer forecast
required paired GID--original source mean difference
$\geq 0.005$ AND at least 8/12 source positives.
A SHA-256 lock on the entire original source-only
manifest is mandatory before reading any target,
even in repeated workflows. No positive forecast
was generated, and an attempted B run stopped
after reproducing divergent byte-level source
covariance signatures before opening B.

\section{Discussion}
This is currently an exploratory study with
a meaningful aggregation threat: it combines
different methods, targets and chronology.
The result does not establish a universal
limit on source-only domain generalization.
Although BNCI2014\_004 and Weibo2014 now provide
\emph{two} concrete same-six-selector matrices,
the four original candidate families have now been compared
on one same-source cohort and exposed held person. A
stand-alone confirmatory evaluation still requires
a precommitted cross-acquisition protocol with
entirely uninspected outcomes and the same information budget,
and an operational measurement such as
source-to-target ranking regret or selection
error rate. New acquisitions must be allocated
at the study level to avoid treating previously
exposed outcome data as confirmations.
Stricter source artifact locking needs
deterministic serialized feature releases
if raw-batch covariance calculations are
not bitwise stable between identical runs.

\section{Conclusion}
Across these distinct attempts, no
nondegenerate new algorithm has established
reproducible positive unseen-person benefit
over the original source-macro scalar LDA.
This result is an engineering
and research agenda, NOT an independently
registered negative-effect finding or
a new accuracy state of the art.
All P1 source-score geometry and P2 clinical
record-identity findings remain
separate scientific claims.
